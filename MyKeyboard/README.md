# اللوحة العربي

لوحة مفاتيح أندرويد (عربي / إنجليزي) مبنية بـ Kotlin عبر `InputMethodService`.

## الميزات
- عربي / إنجليزي مع زر تبديل، وصفحة أرقام ورموز
- ضغط مطوّل:
  - **ا** → أ إ آ ٱ ء
  - **ى** → ى ئ
  - **و** → و ؤ ، **ه** → ه ة
  - **النقطة** → حركات عربية: ً ٌ ٍ َ ُ ِ ّ ْ ـ
  - الحروف الإنجليزية تعرض رموز/أرقام بديلة
- زر بحث/إرسال/تالي يتغير حسب التطبيق (بدائرة مائية)
- **قارئ باركود و QR** مدمج (CameraX + ML Kit) — يضع النص مباشرة في حقل الكتابة
- شريط اقتراحات كلمات
- **ثيمات** (فاتح / داكن / مائي) + ارتفاع لوحة + اهتزاز/صوت من شاشة إعدادات كاملة

## التشغيل
1. افتح المشروع في Android Studio وانتظر بناء Gradle
2. شغّل على جهازك وفعّل "اللوحة العربي" من إعدادات اللغة والإدخال
3. افتح "إعدادات التطبيق" من أيقونة التطبيق لتخصيص الثيم
